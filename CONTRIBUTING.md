# Contributing

Use the build and test commands in [BUILDING.md](docs/BUILDING.md). Keep changes scoped to the native app, MCP server or local demo. The websites and hosted service are maintained separately. The comments roadmap remains unfinished; existing share UI does not imply that pinned comments are supported.

Submit a pull request with the concrete behavior changed and relevant verification. Do not include credentials, real customer or account data, private documents, local agent configuration, build artifacts or logs containing personal information.

By contributing, you agree to license your contribution under the repository's MIT licence. Contribute only code and assets you have the right to submit, including any required employer permission. Preserve the original licence and copyright notices when adapting third-party work, and add its provenance to THIRD_PARTY_NOTICES.md. Disclose generated code and review it for correctness and third-party provenance.

The initial export's selected source history identifies Charlie Ellington as its only human commit author; AI co-author trailers are present in the original development history. Third-party template and bundled-library notices are preserved separately. No other human contributor rights were identified in those selected paths. The repository starts with a reviewed snapshot rather than importing private development history.
